Claude

Connect Claude to Kosmos: claude.ai, Claude Desktop, the mobile apps, Cowork and Claude Code all use the same connection. Claude can then read, for any open matter you have access to, the full record: contacts, rates, activity, events, tasks, proceedings, settlement, documents, highlights, the timeline, witnesses, synced emails and earlier AI conversations. It can search the practice, and it can add timeline facts, witnesses and tasks (it can never edit or delete existing ones). Access is personal: Claude signs in as you and sees exactly what you can see.

Connect

  1. In Claude, open Settings, then Connectors, and choose Add custom connector. (In Claude Code: claude mcp add --transport http kosmos {{ connector_url }} and skip to the sign-in.)
  2. Name it Kosmos and paste this address as the server URL, leaving the OAuth settings as they are: 
    {{ connector_url }}
  3. Click Connect. Your browser opens Kosmos: sign in if you are not already, and click Allow.
  4. Back in Claude, the Kosmos tools are available in every conversation. Nothing is installed on your computer.
